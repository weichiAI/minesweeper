# 📰 扫雷日报 - Minesweeper Daily

复古报纸风格的经典扫雷游戏，融合传统文化与现代游戏体验。

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)

## ✨ 游戏特色

### 🎮 完整扫雷体验
- **三种难度模式**：初级、中级、高级
- **完整游戏机制**：左键揭开、右键标记、双击快速展开
- **计时器与地雷计数**：实时显示游戏进度

### 📜 每日战报系统
- **战绩统计**：今日对局数、胜利次数、胜率、最佳战绩
- **荣誉称号**：从扫雷新手到扫雷传奇，7个等级等你解锁
- **古文名言**：100句精选古人智慧，每次生成战报随机展示
- **一键保存海报**：生成精美复古风格海报图片，分享给好友

### 🎨 视觉设计
- 复古报纸质感背景与纹理
- 优雅的衬线字体，复刻印刷风格
- 深褐色调搭配金、蓝、红点缀色
- 响应式设计，支持移动端
